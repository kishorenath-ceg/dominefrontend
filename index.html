System Workflow Sequence
01. BROWSER ENCRYPTION

Client-Side Cipher

Files and messages are encrypted directly in the user's browser with AES-256-GCM before transmission. Plaintext never leaves the device.

02. SUBDOMAIN EDGE

securedrop.kishorenath.me

Encrypted payload is routed over HTTPS / TLS. Host servers act solely as a secure relay with zero decryption capability.

03. EPHEMERAL TTL

Automatic Expiration

Shared files self-destruct upon single retrieval or after a set duration, ensuring data does not linger permanently.
